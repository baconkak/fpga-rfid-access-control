# FPGA RFID Access Control — คำอธิบายภาษาไทย

โปรเจกต์นี้ใช้ Verilog ออกแบบวงจรตรวจสิทธิ์บัตรบนบอร์ด PYNQ-Z2 ตัวอย่างเช่น บัตรที่มี UID ตรงกับค่าที่บันทึกไว้จะได้ไฟเขียว ถ้า UID ผิดสามครั้งที่เข้าสู่ขั้นตรวจสิทธิ์ ระบบจะล็อกชั่วคราว และมีโหมดเปลี่ยนบัตรที่อนุญาตได้หนึ่งใบ

**ตอนนี้ข้อมูลบัตรถูกป้อนผ่าน VIO หรือโปรแกรมจำลอง ยังไม่ได้อ่านจากบัตร RFID จริง** VIO คือเครื่องมือใน Vivado ที่ใช้เปลี่ยนค่าและดูสัญญาณภายใน FPGA ผ่านสายเชื่อมต่อกับคอมพิวเตอร์

## การทำงานหลัก

- ตรวจข้อมูลบัตรตามลำดับสถานะ ตั้งแต่เริ่มสแกนจนถึงอนุญาตหรือปฏิเสธ
- เก็บ UID ที่อนุญาตหนึ่งใบ และเปลี่ยน UID ได้ในโหมดลงทะเบียน
- ล็อกระบบชั่วคราวเมื่อ UID ผิดสามครั้งที่เข้าสู่ขั้นตรวจสิทธิ์
- ใช้ปุ่มและสวิตช์ควบคุมการทำงาน พร้อมแสดงสถานะผ่าน LED บนบอร์ดที่ใช้ clock 125 MHz
- มี testbench ตรวจผลอัตโนมัติและบันทึกสัญญาณแต่ละรอบ clock ลงไฟล์ CSV

## ทดลองบนคอมพิวเตอร์

ถ้ามี Python และ Vivado 2024.1 ติดตั้งไว้ ให้เปิดหน้าต่างคำสั่งที่โฟลเดอร์โปรเจกต์แล้วรัน:

```powershell
python scripts/run_sim.py --vivado-bin "C:\Xilinx\Vivado\2024.1\bin"
```

ถ้าผ่าน จะเห็น `ALL TESTS PASSED` พร้อมจำนวนรายการตรวจ ไฟล์ผลอยู่ใน `build/sim_xsim/` ส่วนวิธีใช้ Icarus Verilog และสร้างโปรเจกต์ Vivado ใหม่อยู่ใน [README หลัก](../README.md)

รายละเอียดวงจรและข้อจำกัดอยู่ใน [Design notes](design.md) ส่วนผลทดสอบและรายงานจาก Vivado อยู่ใน [Verification](verification.md)
